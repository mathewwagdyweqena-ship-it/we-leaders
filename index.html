إدارة المنصة

تنبيه مهم: هذه النسخة واجهة تجريبية فقط. صلاحيات المديرين الحقيقية وتسجيل الدخول الآمن ومشاركة البيانات بين الأجهزة تحتاج إلى خدمة خلفية وقاعدة بيانات. لا تضع كلمات مرور أو بيانات حساسة في هذا الملف.

نظام الصلاحيات المطلوب

  • المدير الرئيسي: أنت وحدك تضيف المديرين وتوقف حساباتهم.
  • المدير: يضيف الطلاب والمحتوى ويعدّل ما تسمح به صلاحياته، ولا يضيف مديرين.
  • الزائر: مشاهدة فقط دون إضافة أو تعديل أو حذف.

GitHub Pages يستضيف الواجهة فقط؛ لا يستطيع وحده حماية حسابات المديرين أو مزامنة البيانات بين الأجهزة. نحتاج إلى قاعدة بيانات وتسجيل دخول موثوقين لتنفيذ ذلك.
